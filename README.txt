LINE SCANNER PRO V45 · SCANNER PRO NUEVO SISTEMA

Esta versión conserva la aplicación V45 y mejora específicamente el Scanner Pro.

Funciones del Scanner Pro:
- Uno o varios partidos por línea.
- Parser de hándicap y líneas enteras/cuarto (ej. 2-2.5, 2.25).
- Búsqueda del fixture real y estado UPCOMING/LIVE/FINAL.
- Marcador y minuto LIVE cuando API-Football los entrega.
- Estadísticas disponibles: posesión, tiros, tiros a puerta, corners, tarjetas.
- Forma reciente.
- HÁNDICAP / OVER / UNDER con porcentaje y razones.
- MEJOR OPCIÓN.
- CONGELAR DECISIÓN.
- Seguimiento automático de decisiones congeladas LIVE cada 30 s para ahorrar API.
- Liquidación automática al finalizar, incluida división de líneas de cuarto.
- Motor de aprendizaje y patrones similares usando solo resultados liquidados.

IMPORTANTE: la API key se introduce desde Configuración y se guarda localmente en el navegador. No está incluida en este ZIP.
