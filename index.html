01 · SCANNER CENTRAL
🔥 Scanner 01 — Analizar
Catálogo de partidos, líneas de hándicap y goles y análisis en una sola pantalla. Las líneas mostradas se conservan como fuente de entrada; el motor no las sustituye por una línea inventada.
SCANNER 01 · ENTRADA RÁPIDA
📋 Agregar partido manual pegando la línea
Pega uno o varios partidos. Cada línea se interpreta y analiza por separado. La línea que tú escribas es la línea que se analiza; los datos web se usan para contextualizar el partido, no para reemplazar tu hándicap o tu línea de goles.
Formato:
Real Madrid 🆚 Atlet Madrid+0.5 (3)
+0.5 = hándicap/ventaja del visitante · (3) = línea de goles.
También acepta Real Madrid vs Atlet Madrid +0.5 (3) y varias líneas pegadas una debajo de otra.
Listo. Introduce una o varias líneas.
ENTRADA MANUAL

Crear / editar partido

Puedes usar este formulario para introducir un partido que no esté en el catálogo y analizar exactamente la línea que tengas.

ANÁLISIS MANUAL

Agrega tu propio partido

Introduce tú mismo el hándicap y la línea de goles. El motor analiza exactamente esas líneas y las conserva para liquidarlas con el marcador final.

Puedes introducir solo los nombres + las líneas. Si añades GF/GA o xG reales, el motor los usa como información adicional. Si no los tienes, no se inventan. En líneas asiáticas como -0.75 o 2.75, el sistema divide automáticamente las patas correspondientes.

Liquidar cuando termine

Después del partido introduce el marcador final. El sistema liquidará las líneas guardadas para este análisis, incluyendo push, media ganancia y media pérdida cuando corresponda.
